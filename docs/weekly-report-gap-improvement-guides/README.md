# Feature implementation guides

This folder documents implemented product features one by one. Each file states current behavior, the role/workflow/security boundary, and a practical verification path.

- Reports: form, draft/submit, corrections, and version history.
- Manager features: review, team filters, roster, dashboard, and projects.
- Administration and cross-cutting behavior: users, RBAC, validation, responsive UX, tests, and readiness.

Use these guides with [Project reference](../PROJECT_REFERENCE.md), [RBAC](../05-authentication-and-rbac.md), [workflow](../07-review-and-version-workflow.md), and [testing](../15-testing.md).
