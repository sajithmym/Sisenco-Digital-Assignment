## Test widths

## Sidebar
Desktop: fixed sidebar.
Mobile: hamburger + Sheet/Drawer.

## Layout
Desktop:
- KPI cards in rows
- 2-column chart grid

Mobile:
- 1 card per row
- 1 chart per row

## Report task table
Use:
- horizontal scroll, or
- responsive task cards on mobile

## Forms
Desktop: 2 columns where useful.
Mobile: 1 column.

## Professional UX
Add:
- hover states
- focus states
- transitions
- skeleton/loading
- empty states
- success toast
- error toast
- confirmation dialog

## Accessibility
- input labels
- keyboard access
- visible focus
- sufficient contrast
