# Weekly Report Generator — Engineering Guide

This folder contains the implementation plan for the **Weekly Report Generator & Team Dashboard** technical assignment.

## Recommended Stack

- **Frontend:** Next.js + TypeScript
- **UI:** Tailwind CSS + shadcn/ui
- **Forms:** React Hook Form + Zod
- **Backend:** NestJS + TypeScript
- **Database:** PostgreSQL
- **ORM:** Prisma
- **Authentication:** JWT access token + refresh token
- **Charts:** Recharts
- **Testing:** Jest + Supertest
- **Deployment:** Vercel + Render/Railway/VPS + PostgreSQL provider

## Engineering Rules

1. Keep business logic outside UI components.
2. Keep configuration and hard-coded values in dedicated files.
3. Use reusable services, DTOs, hooks, components, constants, and helpers.
4. Follow SOLID principles.
5. Validate all external input.
6. Enforce authorization in the backend, not only in the frontend.
7. Prefer explicit domain rules over hidden behavior.
8. Handle errors consistently.
9. Keep modules small and focused.
10. Write code that can be explained during the live coding round.
