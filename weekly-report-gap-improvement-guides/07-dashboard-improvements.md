# 07 — Manager Dashboard Improvements

## Required KPI cards
Prioritize:
```text
Reports Submitted
Submission Compliance Rate
Needs Correction
Open Blockers
```

Extra cards:
```text
Approved
Team Members
```

## Compliance Rate
Define one clear formula and document it.

Suggested compliant statuses:
```text
SUBMITTED
NEEDS_CORRECTION
APPROVED
```

Pending:
```text
DRAFT
NOT_STARTED
```

## Add Status by Team Member
Prefer a stacked bar chart over only an overall pie:
```text
Member | Draft | Submitted | Correction | Approved | Not Started
```

## Add Recent Activity
Examples:
```text
Kasun submitted Version 2
Sarah requested changes
Nimal's report was approved
Ayesha created a draft
```

## Verify charts use real backend data
- Task completion trend
- Project workload
- Time distribution
- Status distribution

Avoid repeated placeholder totals.
